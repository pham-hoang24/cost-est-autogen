TEST SCENARIO 1: CRM PLATFORM (MEDIUM COMPLEXITY WEB APP)
================================================================================
Project Type: web application
Complexity: medium
Tech Stack: web technologies including React for frontend, Node.js for backend, PostgreSQL database, and AWS cloud infrastructure
Team Size: 8
Region: North America
Project Duration: 3-6 months

Project Description: We are building a customer relationship management (CRM) platform for small to medium-sized businesses. The system will help businesses manage their customer contacts, track sales opportunities, manage marketing campaigns, and generate sales reports. Key features include:

- User authentication and role-based access control (admin, sales manager, sales rep)
- Contact management: add, edit, delete, and search customer contacts
- Sales pipeline management: track deals through stages (lead, qualified, proposal, negotiation, closed-won, closed-lost)
- Task and activity tracking: schedule meetings, set reminders, log calls and emails
- Email integration: sync with Gmail and Outlook for email tracking
- Reporting dashboard: visual analytics for sales performance, conversion rates, and revenue trends
- Mobile responsive design: access from desktop and mobile devices

The platform needs to support up to 1000 concurrent users and should integrate with popular third-party services like Stripe for payments and Mailchimp for email marketing. We expect the MVP to launch in 6 months with core features, followed by iterative enhancements based on user feedback.

TEST SCENARIO 2: E-COMMERCE MOBILE APP (HIGH COMPLEXITY)
================================================================================
Project Type: mobile application
Complexity: high
Tech Stack: Flutter for cross-platform mobile, Firebase for backend, Stripe for payments
Team Size: 12
Region: EMEA
Project Duration: 6-12 months

Project Description: A comprehensive e-commerce mobile application for fashion retail. The app will enable users to browse products, add items to cart, make secure payments, track orders, and manage their profiles. Key features:

- Product catalog with advanced filtering (category, size, color, price range)
- Personalized recommendations using ML algorithms
- Shopping cart and wishlist management
- Multiple payment methods (credit card, PayPal, Apple Pay, Google Pay)
- Real-time order tracking with push notifications
- User reviews and ratings system
- Social sharing features
- Augmented reality try-on for clothing items
- Multi-language support (English, French, German, Spanish)
- Admin dashboard for inventory and order management

The app must handle 50,000+ concurrent users during peak shopping seasons, integrate with existing ERP systems, and comply with GDPR regulations.

TEST SCENARIO 3: AI/ML DATA ANALYTICS PLATFORM (VERY HIGH COMPLEXITY)
================================================================================
Project Type: ai/ml project
Complexity: very high
Tech Stack: Python, TensorFlow, PyTorch, Apache Spark, Kubernetes, AWS Sagemaker
Team Size: 15
Region: Asia Pacific
Project Duration: 12+ months

Project Description: Building an enterprise-grade AI/ML platform for predictive analytics and automated decision-making. The platform will process large-scale datasets, train custom ML models, and provide real-time insights. Core capabilities:

- Data ingestion pipeline supporting multiple sources (databases, APIs, file uploads)
- Automated data preprocessing and feature engineering
- Model training with support for various algorithms (regression, classification, clustering, deep learning)
- Hyperparameter tuning and AutoML capabilities
- Model versioning and experiment tracking (MLflow integration)
- Real-time inference API with sub-100ms latency
- A/B testing framework for model comparison
- Explainable AI dashboard for model interpretability
- Role-based access control with audit logging
- Automated model retraining pipelines

The platform must process 10TB+ of data daily, support 100+ concurrent model training jobs, and integrate with existing data warehouses (Snowflake, BigQuery). Requires robust monitoring, alerting, and compliance with data privacy regulations across multiple jurisdictions.

Complexity: medium
Tech Stack: Enterprise systems (SAP, Salesforce, Oracle), REST APIs, message queues (RabbitMQ)

Region: EMEA
Project Duration: 3-6 months
